# `generateBordereauByParcelsNumbers`

Generates a deposit slip ("bordereau de remise") — the document a La Poste
agent stamps and dates to certify a batch of parcels was taken in charge.
The document is **French-only** and is mandatory specifically for shipments
requiring a CN23 customs declaration (international / overseas).

## Constraint

**All parcels in one call must belong to the same account.** If parcels
span multiple accounts, make one call per account.

**Max parcels per request: 250.**

## Request

- **Header:** `apiKey`
- **Body:**
  - `contractNumber` (string, N6) — account number
  - `password` (string) — legacy field, not needed with apiKey auth
  - `generateBordereauParcelNumberList.parcelsNumbers[]` — the list of
    parcel numbers to include
  - `fields` (optional, `field[]` / `customField[]`)

```json
{
  "generateBordereauParcelNumberList": {
    "parcelsNumbers": ["6A123456789", "6A123456790"]
  },
  "fields": { "field": [], "customField": [] }
}
```

## Response

`200 OK` — binary/PDF document response (standard REST `Response` object
shape in the Redoc schema — treat as a document attachment, same MTOM/XOP
handling as label responses; do not parse by byte offset).

## Field order rule

Same as all SLS methods — **SOAP callers must respect WSDL parameter
order** or get an `Unmarshalling Error` fault.

## Document content (for reference — if building a custom slip instead)

If ever generating the deposit slip layout yourself instead of via the API,
the official template requires (all mandatory, document must be in French):

| Field | Description |
|---|---|
| Titre du document | Fixed: "Bordereau de remise Offre Entreprises Colissimo" |
| Site de prise en charge | 6-digit REGATE pick-up site code |
| Libellé site de prise en charge | Pick-up site label (≤40 chars) |
| N° Bordereau | Sequential slip number, must be continuous (10 digits) |
| Date | Physical parcel delivery date (DD/MM/YYYY) — must match actual drop-off date |
| N° Client | 6-char customer number |
| Réf. expéditeur | Optional shipment reference (≤35 alphanumeric) |
| N° Colis | Full parcel number, sorted ascending |
| Poids | Parcel weight in kg (≤30kg) |
| Non Méchanisable | `1` if non-mechanizable, else `0` |
| Nombre/Poids de colis (page) | Per-page parcel count/weight totals |
| Nombre Total de colis / Poids total | Slip-level totals |
| Nombre de pages | Total pages in the slip |
| Code barre PDF417 | See barcode spec below |

### PDF417 barcode spec (if self-generating)

| Field | Size | Format |
|---|---|---|
| Fixed prefix | 8 | `"DEBBORCS"` |
| Billing account | 6 | N |
| Deposit date | 8 | DDMMAAAA |
| Deposit slip number | 10 | N, left-padded with zeros |
| Parcel number 1..N | 12 each | AN |
| Fixed suffix | 8 | `"FINBORCS"` |

Auth requires the Colissimo contract number + password (sent when the
contract starts) — same credentials used for the Cbox web account at
`https://www.colissimo.fr/entreprise`.
